# Anonymous EVVA package naming

The package has been fully relabeled with public EVVA identifiers in filenames, directories, source references and explanatory materials. This includes supplementary code and workflow folder names. Existing computational logic, candidate/experimental datasets and result numbers were not intentionally changed; the local runnable table and independent checks were executed after relabeling. Because names and strings in code changed, historical file checksums no longer apply, and the current release manifest/checker use newly computed hashes.

Legacy workflows still require external data and may refer to neutralized artifact names which were not shipped. This naming-only adjustment is not a claim of independent reproduction of unavailable confirmation or prospective evidence, nor a test of complete browser replay.
