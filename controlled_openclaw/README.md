# Controlled OpenClaw: Paper Table 3

Run `python3 code/check_table1.py` from this directory to regenerate/compare the 200-candidate, 12-budget **per-budget cells** against the bundled reference. Its `AUBC` values are **printed from `PAPER_AUBC` manuscript constants**, not independently calculated by that original entrypoint. For an independent check run `python3 ../scripts/check_controlled_aubc_from_rows.py` (from this directory), or invoke that script by absolute path from any working directory: it recomputes unrounded means from all 12 budgets for eight methods using the original functions and compares to the preserved printed values with documented absolute tolerance `2e-4` (maximum observed difference `0.000133581349`). See `docs/CONTROLLED_AUBC_RECALC_CHECK.csv`. The historical script and TSV filenames mention Table 1, whereas the authoritative final manuscript labels it **Table 3**. Numeric values and original analysis behavior were not changed.

`original_source/` holds relevant original collector, environment and development/baseline source. It is not a ready-to-run end-to-end data-collection package: the original training/large development data and infrastructure are absent. The three extra score-family columns in the controlled pool are surrogates, not published model reproductions. The EVVA schedule here is in-sample.
